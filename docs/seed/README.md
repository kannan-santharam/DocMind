Drop files here to preload them for every visitor.

`pnpm seed` ingests `docs/ARCHITECTURE.md` plus every supported file in this
folder into the shared namespace, so a recruiter arriving with an empty session
can chat about them immediately.

Supported: `.pdf`, `.docx`, `.txt`, `.md`. This README is skipped.

Filenames become the titles shown in the sidebar, so name them the way you want
them read — `Kannan Santharam — Resume.pdf`, not `resume_v4_final.pdf`.
